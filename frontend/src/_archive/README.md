# Archived legacy pages

These pages belong to an earlier product direction (GPU/compute trading,
investment "vaults", and autonomous trading agents). They are intentionally
**not routed** and **not built** in the current MVP, and they are excluded from
TypeScript and ESLint (see `frontend/tsconfig.json` and `frontend/.eslintrc.json`).

They are kept here so the work is not lost and can be revived in a later phase,
but they are deliberately hidden from the public MVP, which focuses on:

- AI agents (Wallet Watcher, Token Research, Market Research)
- a compute provider marketplace
- Solana devnet task payments
- useful crypto research / monitoring

Do not import from this folder in production code.
